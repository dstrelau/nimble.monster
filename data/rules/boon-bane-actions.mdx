For more tactical depth, whenever a hero gains an action, they instead gain 1 random boon, bane, or normal action (the same KEY attribute must be used for both):

- **Boon Action.** Gain advantage when rolling, +KEY Defense, or +2 Speed with this action.
- **Bane Action.** Gain disadvantage when rolling, –KEY Defense, or –2 Speed with this action.
- **Normal Action.** Spend this action as normal.
